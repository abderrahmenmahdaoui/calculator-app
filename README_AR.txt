آلة حاسبة شبيهة بكازيو — ملفات جاهزة للنشر

المحتويات:
- index.html: الآلة الحاسبة الحالية
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت
- service-worker.js: تخزين الملفات للعمل بعد أول زيارة (بحسب المتصفح)
- icon-192.png و icon-512.png: أيقونات التطبيق

النشر المجاني باستخدام GitHub Pages:
1. أنشئ حسابًا في GitHub إذا ما عندكش.
2. أنشئ مستودعًا جديدًا (New repository)، وسمّه مثلًا calculator-app.
3. ارفع كل الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
4. افتح Settings ثم Pages.
5. تحت Build and deployment اختر Deploy from a branch.
6. اختر الفرع main والمجلد /(root)، ثم Save.
7. انتظر حتى يظهر رابط الموقع في صفحة Pages.

التثبيت على Android:
1. افتح رابط الموقع في Chrome.
2. افتح قائمة ⋮ واختر Install app أو Add to Home screen.
3. اتبع تعليمات التثبيت التي يعرضها الهاتف.

التثبيت على Windows:
1. افتح رابط الموقع في Microsoft Edge أو Chrome.
2. من قائمة المتصفح اختر Apps ثم Install this site as an app، أو استخدم أيقونة التثبيت إن ظهرت.
3. سيظهر التطبيق في قائمة التطبيقات ويمكن تثبيته في Start.

ملاحظات:
- الاستضافة مجانية ضمن حدود GitHub Pages، والرابط يكون عامًا.
- هذه نسخة ويب قابلة للتثبيت (PWA)، وليست APK مستقلة ولا ملف EXE مستقلًا.
- لا ترفع ملف ZIP وحده؛ ارفع الملفات التي بداخله.
- بعد تعديل index.html، ارفع التغييرات إلى المستودع وانتظر تحديث Pages.
- اسم الواجهة الحالي في HTML قد يظهر CASIO STYLE؛ لا تستخدم شعار Casio الرسمي أو توحي بأن التطبيق رسمي أو تابع لشركة Casio.
